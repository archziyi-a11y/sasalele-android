# V36 工具条深色主题与拖动

目标：深色模式下悬浮工具条各入口可辨，展开和收起状态均可拖至屏幕两侧。

约束：保留窗口范围、面板显示就绪逻辑、收起高度、拖动位置持久化和返回键行为；不修改业务界面。

验收：在深浅主题、标准与小屏下分别拖至左右边缘并收起展开，检查入口可见、位置保留、窗口不越界；旋转或改变显示尺寸后复测。构建与设备验证由主协作者完成。

## 验证与交付（2026-11-03，北京时间）

- 根因：工具条多数图标固定深灰；dragX 原先仅允许半屏距离。
- 改为主题 onSurfaceVariant / surface；横向边界使用屏幕宽减窗口宽，纵向同步约束。手势监听随屏幕尺寸、密度和展开状态重建，避免配置变化沿用旧边界。
- 正式签名构建 assembleRelease、productionPreflight、lintVitalRelease 通过；签名与既有发布一致。
- 模拟器 API 36：深/浅色 × 1080x2400/720x1600 × 展开/收起 × 左/右边缘，共 16 个位置检查通过。每轮收起后可重新展开。主题与显示尺寸在运行中切换。
- 截图、边界数据及脚本：evidence/native-ui-v36/。首次小屏检查因 dumpsys 使用物理坐标、输入使用逻辑坐标失败；修正观测脚本坐标换算后重测通过，未改变产品判断阈值。
