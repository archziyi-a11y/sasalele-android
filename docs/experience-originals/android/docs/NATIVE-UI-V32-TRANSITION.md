# V32 悬浮窗口切换修正

目标：跟进、设置及其他面板从工具条打开、关闭或展开时，先完成原生窗口边界调整，再显示目标内容，避免内容在旧窗口尺寸中短暂挤压；不引入人为慢动画。

业务约束：保留真实业务数据、客户和生成草稿状态、窗口外触摸透传、图片选择隐藏恢复、键盘和系统返回顺序；窗口尺寸随屏幕配置调整。

失败场景：目标内容先被旧的 72dp 窗口测量；切换面板与展开状态分帧更新导致两次窗口调整；窗口尺寸未就绪却展示内容；键盘或横竖屏变化导致等待窗口永不恢复；关闭或取消等待时留下不可操作透明窗口。

验收依据：编译通过后，在模拟器及目标工作机分别录制工具条→跟进/设置、侧栏→展开→收起和关闭，逐帧检查内容不挤压、不闪烁；同时复测窗口外触摸、系统返回、键盘和屏幕尺寸变化。编译结果不能替代设备体验验收。

## 实现及验证结果（2026-11-02）

v31 基线录屏复现了设置内容先挤入工具条窄窗口、随后展开的跳动。面板内容更新早于原生窗口尺寸生效，展开状态另一次更新还可能产生第二次调整。

v32 将面板切换与展开状态复位合并，等待原生窗口实际布局就绪后展示目标内容；同一面板调整尺寸时保留输入状态。关闭时按工具条实际内容高度恢复窗口，修复残留整屏透明高度及工具条位置跳动。没有添加延迟动画。

最终 release 包模拟器验证：

- 设置、跟进打开录屏逐帧检查未再出现窄栏挤压；系统返回关闭后，工具条位置和尺寸与打开前完全一致。
- 物料搜索键盘、面板展开及返回隐藏键盘正常；720×1280、density 320 下主要操作保持可见；测试后恢复模拟器显示设置。
- release 构建、productionPreflight、lintVitalRelease 通过；签名与原版本一致。

证据位于 `evidence/native-ui-v32/`：基线 `before-settings.mp4`、`before-frame-2.png`；最终包 `final32-settings.mp4`、`final32-followups.mp4` 及对应帧图；工具条边界断言 `final32-bounds.json`。其余中间录屏不作为最终验收证据。

本轮使用模拟器，无真实工作机连接；跟进为未配置工作号的页面状态，不能代替真实联系人列表及工作机流畅度验收。本轮未重复验证相册、分享或真实模型业务，也未部署生产服务或全员手机。
