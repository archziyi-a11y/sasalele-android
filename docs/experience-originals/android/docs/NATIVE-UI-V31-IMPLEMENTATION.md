# V31 原生界面迁入记录

目标：将已认可的交互原型迁入 Android 原生悬浮助手，支持回复、物料和跟进后返回微信，并保留客户资料、销售指导和设置。

业务约束：沿用现有业务接口与工作号/客户双重身份校验；草稿按客户和任务类型隔离，关闭或切换面板保留，晚到结果不得写入其他客户或覆盖生成期间的编辑；保留物料个人名称和团队名称关系、真实图片复制分享以及跟进现有操作；不迁入原型模拟数据。

关键失败场景：窗口覆盖聊天导致无法操作；键盘遮挡输入和操作；客户/任务切换后返回写错草稿；请求失败或重新生成覆盖编辑；选图不能回到业务；工作号未配置时无法返回原任务。

验收依据：离线编译与相关测试通过后，在 Android 设备上验证三条任务、侧栏外微信操作、键盘和返回、小屏大字号、深浅主题、客户切换与晚返回，分别记录模拟与真实业务证据；未实机验收不宣称通过。
