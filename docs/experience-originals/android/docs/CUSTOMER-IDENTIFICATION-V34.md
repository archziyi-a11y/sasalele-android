# V34 客户识别与画像

目标：让销售从实际识别名称快速找到客户，核对可读身份后直接查看画像；缺少画像时由销售主动生成。

约束：只处理已允许的聊天标题区域；排除场景不搜索；工作号过滤与后台确认身份校验不变；不改变画像生成接口，不读取生产样本或发起真实生成。

失败场景：截断名称误判、同名候选误选、切换工作号后旧请求返回、确认失败误进入画像、缺失与服务失败混淆、裁剪暴露正文。

验收：离线编译和相关测试后，使用合成数据验证候选选择、直接确认、失败反馈、缺失/已有画像；在隔离设备检查真实截图裁切及键盘，不以模拟测试宣称生产验收。

## 实现与审计结论（2026-11-03）

Terra 6.1 实现，主代理审查、修正并构建。识别结果优先完整备注，剔除返回箭头/未读数，提供有效名称片段；点击词条搜索，铅笔手动编辑。预览使用 OCR 实际裁切范围。当前工作号及重截图、选图、诊断移入菜单；候选展示头像/备注/昵称，点击查看画像调用原 confirm 校验后进入，不显示内部ID。

画像初次只读取，生成/更新需显式点击；生成不再依赖历史来源字段。失败保留已有摘要，加载失败提供重新加载；切换客户重置生成触发状态。主代理修正显示位图销毁时过早recycle可能造成绘制异常的问题。窗口过渡代码保持v33。

验证：22项离线单元测试通过；release构建、productionPreflight、lintVitalRelease通过。新增2项Compose合成接口测试在正常分辨率及720×1280/density320各通过一次，覆盖点选名称、后台确认、显式生成、失败保留旧画像、切客户不误生成、读取失败重试；小屏额外使用合成截图检验裁切预览。证据位于 evidence/customer-ui-v34/，接口均为本机合成服务，无真实模型及生产业务写入。测试后恢复模拟器显示配置。

局限：尚未在真实微信截图和工作机上验收；标题预览沿用现有OCR裁切范围，真实机裁切效果待核对；本轮不是所有同名/异常账户组合的穷尽验证。未向员工手机批量发布。
