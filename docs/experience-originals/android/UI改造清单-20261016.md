## A. 浮窗交互架构

| # | 改动 | 原因 | 状态 |
|---|---|---|---|
| A1 | **保留「点击面板外收起」，不改** | 这是标准做法（Compose Popup/Dialog 的 outside dismiss 同样不回传触摸）。此前误判为缺陷，已更正 | ✅ |
| A2 | **不做「全屏 ↔ 半屏」双状态切换** | 半屏吸附态的立足点就是「浮层不覆盖那一半」，因此那一半的点击直接给了聊天 App，浮层收不到 → 「点窗口外退回上一状态」物理上无法实现 | ✅ |
| A3 | **面板按物种分四类，模态性各不相同**（见下表） | 「点外部收起」与「底层可操作」互斥，必须按面板的用途分别取舍，而不是按状态切换 | ✅ |

### A3 细化：面板物种与形态

| 面板 | 物种 | 形态 | 退出方式 |
|---|---|---|---|
| 帮你回 / 润色 | 生产型 · 编辑器 | 编辑工作台，专注态，占满键盘以上空间 | 关闭按钮 |
| 常用素材 | 取用型 · 取用器 | 非模态，窗口只包住面板，不挡聊天 | 关闭按钮 ⚠️（贴哪边待定） |
| 销售指导 | 阅读型 | 非模态侧贴 | 关闭按钮 ⚠️（贴哪边待定） |
| 设置 / 待处理提醒 / 客户资料 | 消费型 | 保持全屏 + 点外部收起 | 点外部 / 关闭按钮 |

## B. 「帮你回 / 润色」升级为编辑工作台 ★ 本轮核心

**背景**：当前草稿是只读 `Text`（`BusinessGenerationPanel.kt:81-87`），用户根本无法在面板内修改，只能整段复制走再回聊天框改。而产品目标是要对比「AI 原稿 vs 用户最终复制走的句子」来优化话术生成 —— **这个数据闭环现在是断的，一条都采不到**。

| # | 改动 | 原因 | 状态 |
|---|---|---|---|
| B1 | 草稿改为**可编辑的多行输入框**，预填 AI 原稿 | 当前只读，需求 0 实现 | ⬜ |
| B2 | 编辑区上方加**语境条**：客户最近几条消息切片（只读、可折叠） | 生成依据就是这段切片，系统已有；搬进面板后用户改稿不必翻聊天，且这份切片正是要存的训练语境 | ⬜ |
| B3 | 主 CTA 从「复制草稿」改为「**确认并复制**」，点这一下才落库最终稿 | 用户在聊天框里再改的话最终稿会丢；必须让「改」发生在面板内并用明确动作钉住 | ⬜ |
| B4 | 编辑态**占满键盘以上的空间**，不用半屏凑合 | 一段话术常有 3~6 行，现在实际只有 4~5 行可见高度，改不开 | ⬜ |
| B5 | 新增**草稿样本表**（db 现只有 material / guidance_messages / reminders） | 字段建议：原稿、最终稿、是否修改、workAccountId、friendId、切片起止、原稿生成时间、定稿时间 | ⬜ |
| B6 | 「**写回聊天输入框**」通路（AccessibilityService 或剪贴板引导） | 二期可选。能同时消掉「粘贴要关面板」的来回 + 堵住最终稿流失 | ⬜ |

## C. 面板骨架与视觉规范（源自本轮 UI 评审）

| # | 改动 | 原因 | 状态 |
|---|---|---|---|
| C1 | 每个面板加**显式关闭按钮**，把没人调用的 `onClose` 接上 | 3 个面板声明了 `onClose` 却从未使用，header 的关闭按钮被删过；只靠点空白可发现性不足 | ⬜ |
| C2 | 换掉 5 个语义错位的图标 + 加**短文字标签** | 提醒=红心、素材=扳手、指导=星星、客户=通用人形；6 个里 5 个错 | ⬜ |
| C3 | 面板尺寸改**弹性**，不写死 `280×400dp` | 实测约 80% 面积是空白，且不响应字号缩放/横屏 | ⬜ |
| C4 | 建**品牌色板 + 字号阶梯**，关掉 `dynamicColor`，把白红品牌资产落进 UI | 当前主色由用户壁纸决定，同款 App 在不同手机上颜色不同；`Color.kt` 还是 AS 模板紫色 | ⬜ |
| C5 | 补**深色模式**，清掉硬编码颜色 | 满屏 `Color.White` 硬编码，切深色后浮窗仍是纯白块 | ⬜ |
| C6 | 面板标题与入口名**对齐** | 常用素材 →「销售物料」；帮你回 →「真实业务草稿」；销售指导 →「真实业务上下文」 | ⬜ |
| C7 | 统一**空 / 加载 / 错误态**规范 | 各面板各写各的，提醒面板只有一个居中灰字 | ⬜ |
| C8 | **文案去术语化**，面向一线销售 | 现文案含「按双标识取得近期聊天」「上下文预算」「别名索引…数量对齐（非实时快照）」等 | ⬜ |
| C9 | 设置面板**收起管理员/开发入口** | 「管理员发机配置」「开发诊断」平铺在销售日常面板里 | ⬜ |
| C10 | 清理**假数据与残留文件** | `picsum.photos` 狗图当示例素材；源码目录残留 `FloatingWindowContent_append.txt` | ⬜ |
