## 完整性与边界

各目录 manifest.json 列出原始来源、原件与归档 SHA-256、保留方式和具体处理原因。full-original 表示逐字节保留；minimal-redaction 表示仅处理确认的实际公司数据或秘密，其余内容保留。历史本地原件不修改。

既有删改导出版保留用于追溯，本目录是经验原文优先阅读入口。历史命令、设备状态和部署结论只适用于文档所记时点，不构成当前操作授权。文档提及的数据库、客户资料、密钥、安装包及备份不随本归档自动包含。
