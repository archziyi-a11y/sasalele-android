## 执行规则

- 先使用现有私聊和当前屏幕可见信息核对，**不要求先发送测试消息、不需要断网**；若追加收发实验，另行准备明确的观测条件。
- 手动启用无障碍和输入法；由郭子仪人工确认当前微信工作号。探针不能从微信可靠证明账号身份。
- 每项记录 `通过 / 失败 / 未测 / 不适用`，附复现摘要。不要将完整聊天正文或真实画像复制到验收记录。
- 页面和分类行为以真机实际结果为准。`UNKNOWN` 表示私聊结构证据不足或矛盾，不是因为客户名单未覆盖，也不等同于“确认不是私聊”。

## B. 分类门槛与微信界面读取

- [ ] 微信当前处于可见窗口时，探针有读取结果；群聊/公众号、离开微信、疑似微信导航或关闭读取后，旧绑定清除；UNKNOWN/覆盖暂挂快照并禁用候选插入。
- [ ] 群聊、公众号、通讯录等页面只做页面分类，不读正文、不匹配画像。记录每种页面的实际类别或 `UNKNOWN`。
- [ ] 验证群聊识别依赖顶栏控件/括号人数等启发式；若页面未识别，不得继续读正文。
- [ ] 验证公众号识别依赖顶栏节点启发式；若页面未识别，不得继续读正文。
- [ ] 选定结构正常的真实私聊后记录顶栏候选名称及节点可读性。私聊分类由顶栏、返回、聊天详情、微信编辑框等结构组合判断；已验证样本别名不参与分类门槛。
- [ ] 使用一条**不在已导入样本名单中的真实私聊**核对：若结构满足私聊条件，应仍分类为 `PRIVATE` 并读取当前可见节点；客户匹配不能自动产生该名单外对象的画像绑定。
- [ ] 若结构证据不足或矛盾，结果保持 `UNKNOWN` 并记录具体缺失结构；不得将名单未覆盖写作 UNKNOWN 原因，也不得当作“确认不是私聊”。
- [ ] 对 `PRIVATE` 页面展开读取结果，核对当前可见消息节点和草稿。记录漏读、重复、顺序、文本不可读等情况；当前可见节点不代表完整历史。
- [ ] 核对消息气泡左右位置的方向推断，仅记录与人工观察是否一致；位置不能证明发送者身份。
- [ ] 检查分类误判：客户昵称/备注以数字括号结尾（例如“某昵称(3)”）可能被群聊启发式错分；群聊如不含预期标记也可能漏判。记录假阳性、假阴性及对应节点证据。
- [ ] 消息左右位置方向推断与人工观察一致性需单独记录；界面推断不能当作可靠身份/方向事实。
- [ ] 进入群聊、公众号或其他非私聊后，私聊正文、画像匹配及绑定不再可用，之前的绑定和候选清除。

## C. 画像导入与候选匹配

- [ ] 专用包无需文件导入，首次启动自动载入 [工作号尾号已脱敏] 工作号两条已核验身份样本；核对样本数，摘要均为空。
- [ ] APK 按用户要求内置身份样本，不包含凭证或聊天正文；私人资产源文件与专用 APK 被版本控制忽略。
- [ ] “查看本地画像名单”显示样本来源及摘要更新时间；核对真实私聊对应的别名是否覆盖顶栏实际显示名称。
- [ ] 只在 `PRIVATE` 且当前编辑框为微信时允许选客户；其它页面不出现业务客户候选。
- [ ] 核对抽样文件当前为 2 条双键核验记录且画像摘要为空；导入后 UI 应呈现“暂无摘要”等空摘要状态，不得暗示已具备画像内容。
- [ ] 客户候选仅来自手动选定工作号下已导入且 `chat_verified` 的样本。名称命中只是候选排序/标注线索；需操作者肉眼确认后才建立绑定。
- [ ] 测试名单外私聊、重名和别名未覆盖：名单外私聊仍可被结构分类为 `PRIVATE`，但不可被误绑定到另一客户；重名/未命中候选必须人工核对，记录实际候选行为与误匹配风险。
- [ ] 测试跨工作号画像样本不进入当前工作号候选；切换工作号后旧绑定失效。人工选择工作号仍不能证明微信当前登录身份。
- [ ] 切换手动工作号后旧绑定立即失效；记录应用无法证明微信实际账号的限制。
- [ ] 点“清除客户缓存并停用内置样本”后只保留虚构示例，重启仍停用；“恢复内置身份样本”重新载入两条记录。卸载清理应用数据，另存 APK/JSON/导出文件需单独删除。

## D. 输入法操作与旧结果失效

- [ ] 确认面板有“回复 / 客户 / 诊断”三个清晰分区；底部“插入输入框”和“切系统键盘”在内容滚动时仍可见。此项模拟器已检查，仍需真机复核。
- [ ] 在系统亮色、暗色及大字体设置下检查正文、输入框、按钮文字的对比度和布局；模拟器已检查，OPPO 真机表现待核验。

- [ ] 在微信私聊编辑框打开输入法；面板显示页面类别、标题、当前生成对象/未确认状态和匹配画像来源。
- [ ] 切换到工作号 [工作号尾号已脱敏] 的目标私聊，手动选定并确认候选后，尝试“固定候选”，确认产生的是本地固定测试文字，不是 LLM 输出。
- [ ] “迟到响应8秒”：触发后在等待期间切换客户/会话或退出微信，确认旧响应被丢弃、不会进入新对象的候选。
- [ ] “取消请求”后确认候选清除/取消记录生效。
- [ ] 点“插入输入框”后核对固定文本仅插入微信当前编辑框，无自动发送。
- [ ] 点“切系统键盘”可切回上一个输入法或弹出键盘选择器；返回探针后检查是否复用当前私聊快照和绑定。若微信发出窗口状态事件而触发疑似导航，应重新确认客户并记录该现象。
- [ ] 同一私聊首次完整读取后，复开键盘应继续结构复核并保留原正文快照；键盘开合本身不直接清绑定。手动“更新上下文”应重新读正文并清除旧候选。疑似微信导航应触发重读及重新确认。特别记录微信是否在键盘开合时发窗口状态事件；若有，可能误触发重读。
- [ ] 在本地输入框练习可以验证输入法交互，但记录为本地演练，不能替代微信私聊真机验收。

## E. 脱敏记录和异常情况

- [ ] “保存脱敏测试记录 JSON”可保存；检查导出包含事件、耗时、设备/系统版本、页面分类/节点数，不含聊天正文、画像正文、客户名称或标识。
- [ ] 私聊消息与草稿只在应用进程内存展示；群聊/公众号、离开微信、疑似导航后核对绑定清除；UNKNOWN/覆盖期间核对快照暂挂且不能插入。
- [ ] 无障碍服务断开、窗口读取失败或私聊结构证据不足时有明确待核对状态；UNKNOWN 不能由画像名单是否覆盖决定。
- [ ] 快速切换私聊/非私聊、账号或输入框时，旧内容/候选不留在新对象上。
- [ ] 记录发现的崩溃、节点缺失、错分或错误客户匹配；未复测的问题保持未测/失败，不因 APK 可安装而判整个探针通过。
