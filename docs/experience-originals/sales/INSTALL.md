# Android 真机探针安装说明

> **当前状态：0.1.6 安装包已交付，待 OPPO 真机验证。** 构建、lint、签名/权限检查及模拟器 StateChecks、复开键盘 smoke 通过；这些结果不替代 OPPO A5x 5G / 微信 8.0.70 实测。

## 测试目标

- 操作者：郭子仪。
- 手机：OPPO A5x 5G，Android 15。
- 微信：8.0.70。
- 目标工作号：尾号 [工作号尾号已脱敏]。设备上的工作号由操作者手动选定，探针无法独立证明微信当前登录账号。
- Android 应用包名：`cn.qmyl.probe`；应用名：屹立销售真机探针。

本轮先使用已有私聊页面和当前可见内容，**不要求先发送测试消息，也不需要断网**。后续确需收发测试时另行说明账号、对象和观测条件。

## 安装 APK

1. 从 [安装包](../deliverables/qmyl-probe-0.1.6-sample-debug.apk) 取得 APK，版本 `0.1.6-probe`，大小 100,638 字节；SHA-256 `24d656d48f789e77d8202af3a301c43585660ce9249d23012a21176a9d878e03`。这是调试签名测试包。
2. 将 APK 复制到手机并打开安装。可按手机当前系统提示处理安装确认；OPPO A5x 5G 的来源授权菜单名称和路径尚未真机核实，本说明不预设具体菜单。
3. 安装后启动“屹立销售真机探针”，确认首页标题“销售助手 · 真机探针”和版本 `0.1.6-probe`。

## 启用服务

首次使用本版会自动弹出“首次使用 · 启用功能”引导，显示无障碍服务、输入法启用状态及当前输入法。可点“前往无障碍设置”“前往输入法设置”，完成系统确认后返回，状态会更新；也可点“选择探针输入法”打开系统选择器。点“稍后设置”可跳过，首页“授权与启用引导”可再次打开。弹窗不替用户授权、不自动开启微信读取；启用服务后仍需确认工作号并开启本次读取。

探针首页提供以下系统入口按钮：

1. 点击“2 · 打开系统无障碍设置”，在系统页面手动启用“屹立销售私聊读取探针”，再返回应用。OPPO 菜单实际名称/路径待设备核实。
2. 点击“3 · 启用探针输入法（系统设置）”，在系统页面启用“屹立销售探针输入法”。菜单实际名称/路径待设备核实。
3. 可在首页点“切换输入法”，或在微信输入框弹出键盘后通过系统键盘切换器选择探针输入法。首次启用和切换步骤须在真机补记。
4. 点“选择当前工作微信账号”，由操作者核对并选择“[工作号名称已脱敏] · 尾号[工作号尾号已脱敏]”。**这个选择只是人工声明，应用不能验证微信实际登录账号**；若手机当前号无法确认，停止客户匹配测试。
5. 点“1 · 开启 / 关闭本次微信读取”，确认对话框后开启。读取仅在本次手动开启时工作；也可随时点同一按钮关闭。

## 内置身份样本（无需手机导入）

1. 当前 0.1.6 专用测试包内置两条身份样本，首次启动自动载入，无需在手机端导入文件。保留“导入客户画像 JSON”作为可选的扩展入口，限制 2 MB、最多 500 条。
2. 默认抽样工具针对 [工作号尾号已脱敏] 号，身份依据方舟工作号与好友 ID 双键验证。导入的是已有画像和名称别名，不包含方舟登录凭证。
3. 内置样本含 2 条经方舟账号 ID 与好友 ID 双键核验的记录；两条摘要均为空，只有身份/别名信息，没有可供回复生成的画像摘要。不包含访问凭证或聊天正文。
4. **私聊分类不依赖画像名单或名称别名。** 分类依据微信顶栏/返回/聊天详情/编辑框等结构特征，并先排除可识别的群聊、公众号及其他页面。`UNKNOWN` 表示这些结构证据不足或互相矛盾；名单未覆盖不会单独导致 `UNKNOWN`。
5. 客户候选仍只来自手动选定工作号下已导入、`chat_verified` 为真的记录。顶栏名称命中只标为名称匹配候选；未命中时也可能显示人工核对候选。候选列表不证明当前私聊对象身份，须由操作者检查后确认。抽样名单没有的真实私聊仍可分类并读取可见节点，但无法自动匹配画像记录。
6. 可在首页“查看本地画像名单”检查记录。“清除客户缓存并停用内置样本”清理活动样本并持久停用，重启不会自动恢复；“恢复内置身份样本”可主动重新载入。APK 内的样本本体不可在应用内删除，清除操作也不会删除手动导入的原始 JSON。

## 开始真机核对

0.1.6 延续“回复 / 客户 / 诊断”三区面板与固定底部操作栏，并增加同一私聊上下文复用：首次完整读取后持续复核结构、保留正文快照；手动“更新上下文”重新读正文并清旧候选。键盘开合不直接清绑定。UNKNOWN/覆盖暂挂快照并禁用候选插入；群聊、公众号、离开微信及疑似导航清旧绑定。疑似导航会重读并要求重新确认，因为 windowId+title 无法证明同名私聊唯一。若微信在键盘开合时也发窗口状态事件，可能误触发重读，须 OPPO 实测。

选择候选后，顶部显示“待确认”；点击“对象正确，绑定”后显示绿色“已绑定”。点选候选不等于完成绑定，失败会提示原因。名称和状态是本机界面反馈，不写入导出。

真实微信分类和时间行为仍未验证。UNKNOWN 会自动记录结构诊断：控件类型、标识、位置、字符长度、已知分类关键词和编辑框数量；不保存原始昵称、顶栏描述或正文。相同未知会话最多每 30 秒重复记录。窗口读取异常也自动记录。程序不能自行认出所有错分；看到分类或客户匹配不正确时，点“记录错误”并选择项目，才会保存人工错误标注与当时诊断。

复测旧私聊和群聊时无需发送消息：先确认 [工作号尾号已脱敏] 工作号并开启本次读取，依次打开一个旧私聊、一个群聊，查看类别；发现错分可标注，最后回首页“保存脱敏测试记录 JSON”。UNKNOWN 本身并不证明该界面属于哪一种会话。

**必须：** 在微信中核对实际登录的工作号，并核对当前是一对一私聊后再确认客户、插入候选。探针只按人工选择的工作号过滤客户；如果选错号或误认会话，可能把另一客户的上下文带入当前编辑框。

1. 在微信中由操作者确认尾号 [工作号尾号已脱敏] 工作号，并打开一对一客户私聊。无需新发消息；可用现有屏幕上可见的内容核对探针输出。
2. 切到探针输入法，核对界面类别、顶栏名称和可见节点；在需要时点“展开读取结果”。界面会提示需要人工核对客户身份。
3. 操作者点击“选择客户”，检查候选、工作号和顶栏，再点“对象正确，绑定”建立本次绑定。名称相符只是候选依据；重名及人工选择均不能证明微信好友身份。
4. 测试固定候选、8 秒迟到响应丢弃、取消请求、插入输入框和切系统键盘。插入后由操作者目视核对；探针不自动发送。
5. 需要保存记录时点“保存脱敏测试记录 JSON”，选择保存位置。导出包括事件、设备/系统版本和节点数量等，不含聊天/画像正文、客户名称或标识；测试结论仍由操作者核对并填写验收清单。

## 读取范围与已知限制

- 仅在微信当前可见窗口中进行读取。首轮只读取顶栏结构与分类所需的少量信息；只有分类为 `PRIVATE` 才继续读取当前可见消息节点和输入框草稿。
- 群聊、公众号及其他页面不读取正文、不匹配画像；由顶栏节点启发式分类，结果需真机核对。昵称带数字括号（如末尾人数样式）可能被误判成群聊；异常标题结构也可能让非私聊被识别成私聊。遇到错误分类要记录并修正，不能把规则输出当作身份事实。
- 私聊分类不查画像名单；只有 `UNKNOWN` 的结构证据不足/矛盾时才停止正文读取。已识别为 `PRIVATE` 的真实私聊即使样本名单未覆盖，也会尝试读取当前可见无障碍节点；客户匹配仍只能从已导入并验证的账号样本中选。
- 读取结果仅保存在进程内存用于界面核对；测试事件可由用户主动导出。探针没有网络权限，不接 LLM。
- 无障碍节点不等于完整聊天记录：只反映微信当前提供的可见节点，可能漏掉屏外、折叠、虚拟化或未暴露的气泡；不代表完整历史。
- 本版不翻页、不自动滚动、不做截图 OCR；图片/语音只能看到微信公开的节点描述，不等于完整内容已读。
- 展开读取结果也展示分类区域的顶栏节点、控件描述和标识，供 UNKNOWN 与错分校准；不会因此读取非私聊正文。
- 面板与导出记录本机扫描耗时，不能当作微信到方舟的同步延迟。每约 5 秒记一次扫描指标；最近 300 条事件约每 10 秒自动保存到应用私有目录，重启可恢复；强行退出可能丢失尚未保存的末尾事件。
- 消息左右位置仅用于方向推断，不是可靠的发送者身份凭据；须由操作者核验。
- 工作号由操作者手动选择，不能证明设备上实际当前登录的是该号；客户绑定也须操作者肉眼确认。
- 不自动点击微信发送；“插入输入框”只提交文本到当前编辑框。
- 输入法切换记录 API 调用耗时和请求到本面板关闭的时间；后者不是目标键盘完全可见的时间。无切换历史时尝试另一个已启用键盘，无可用键盘则打开系统选择器。

## 停止与卸载

测试完成后关闭本次读取开关；需要时在系统设置关闭无障碍服务、停用探针输入法。卸载清理安装副本及应用私有数据；手机上另存的 APK、手动导入的 JSON 和主动导出的记录不会随卸载删除，需要另行删除。内置样本可以从 APK 提取，本专用测试包因此包含真实身份信息。系统卸载菜单路径待 OPPO 真机核实。
