# 交互原型首版审计

对象：Terra 6.1 实现的离线浏览器原型。主代理审计。

- 回复：生成、修改结果、补充问题、关闭重开、切换功能后保留；不同客户和回复类型分别保存。
- 物料：本机／团队切换、搜索筛选、图片预览、改名保存、复制／分享反馈。
- 跟进：复制姓名、已处理、稍后、忽略与恢复。
- 导航：紧凑／展开、关闭、返回；侧栏外聊天可操作。
- 状态：加载与失败区分，重试，已有内容保留。
- 布局：标准尺寸与小屏大字体，键盘模拟，深浅主题，页面无横向溢出。
- 交付：离线资源加载、无控制台异常、场景内容为合成示例。

记录浏览器原型实际验证结果；原生 Android 安装、系统键盘与微信分享留到实现阶段。
