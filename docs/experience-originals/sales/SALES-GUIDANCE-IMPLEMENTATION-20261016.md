# 销售指导实装报告

2026-10-16（Asia/Shanghai）。本机代码、构建和验证完成；服务器与真机尚未升级至本轮版本。工作机当前仍为v13，服务器仍是用户此前确认的v2.1。

## 范围

按用户指示暂停帮我回业务效果验收，待知识库接入后继续。本轮只实现星星图标当前已确认客户的模型指导，不恢复旧模拟排行榜、虚构CRM事件或自动跟进。销售指导面向销售，给分析和下一步，区别于发给客户的回复。

## 实现

服务复用已部署的 /sales/draft 接口，request_type=销售指导；仍受工作机授权和客户双标识人工确认保护。队列、幂等、客户隔离与错误处理沿用现有机制。读取当前限定聊天并确保画像，再进行一次独立指导模型调用；已有画像不变时复用，不强制重生成。

结构输出 guidance：assessment、evidence（message_id、observation）、next_steps（最多3条）、missing_information与cautions（各最多5条）。服务验证字段、长度和消息ID存在性，拼成可读的内部指导保存；不声称已验证证据语义完全一致。旧业务提示词版本仍 sales-business-v2.1；指导独立 sales-guidance-v1，不无故使所有画像版本失效。

Android BusinessGenerationPanel增加独立guidanceOnly模式，星星路由进入此模式，隐藏回复/润色切换与原文必填框，提供补充局面和生成销售指导按钮。结果可阅读、编辑备注及复制，明确内部参考、不会自动发送。空客户时禁止提交。

知识库输入仍为空；提示词禁止确认现行价格、优惠、开班、名额、师资、交通和住宿，要求先内部核实。基于已有聊天的需求梳理可做，不将其称为已有政策知识。普通询价/好的不推断高意向；退款抗拒优先停止促销。
