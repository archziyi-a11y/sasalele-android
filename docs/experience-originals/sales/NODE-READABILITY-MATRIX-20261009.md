列表出现动态导入提示条，改变了行坐标；第一次命令标签 private_A 实际进入群聊 A，已按截图修正，不能算私聊样本。随后拟进入私聊时微信退出登录并出现账号异常提示，命令仍名为 private_A，但实际是异常弹窗，同样按截图修正。未发送消息或下载群文件，未输出或归档聊天正文；界面树只用于结构计数，设备上的该次原始 XML 随后删除。临时截图用于确认页面，没有放入项目交付目录。

计划中的 3 个私聊、第二个群聊和公众号未完成，原因是登录态中断。此前同一私聊的空节点复核见 VERIFICATION.md；不能用它充作本轮 3 个不同私聊。

可支持的结论：独立抓取在探针页、系统设置和微信异常弹窗可用，微信列表和所测群聊返回空结构。问题存在页面差异；不是所有微信窗口都不可读，也不能单凭这些结果证明微信主动屏蔽、模拟器不兼容或探针分类错误。账号异常的原因未知，时间上的先后不构成因果证据。

下一项所需条件：用户按微信自身指引恢复登录态后，补齐剩余页面；同时保留异常弹窗可读的正对照。无需重新安装、清数据或反复尝试登录来制造样本。
