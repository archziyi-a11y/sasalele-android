# 销售助手浮窗开发计划

更新：2026-10-10，Asia/Shanghai。状态：设计已确认，待开发与验证；不代表现有 APK 已实现。本文保存产品决定，不替代历史探针记录。

## 目标与开发路径

销售人员在微信客户一对一私聊时，通过竖向浮动工具条识别并绑定客户、查看画像、获取回复与销售指导、使用宣传素材。发送由销售人员完成。

本阶段采用用户主动截屏、静态图片识别和手动客户绑定；不依赖持续读取微信节点或自动跟随会话。模拟器无需登录微信即可完成主要开发：使用本地模拟聊天页、导入图片、画像样本、模拟消息事件和真实模型。既有无障碍探针的测试记录保留；其持续扫描不作为本方案的前置依赖。

“无需微信登录即可开发”不等于所有集成均已验收。最终需验证系统截图授权、浮窗与键盘共存、剪贴板/分享、后台提醒及真机环境；方舟接入还需单独验证账号和客户映射、入站/出站方向、消息去重与同步时效。一次未出现安全警告不能证明没有风控风险。

## 已确认的五个入口

| 顺序 | 功能 | 交互 |
|---|---|---|
| 1 | 识别客户 / 客户头像 | 未绑定显示识别图标；长按截屏识别、搜索画像，确认后替换为客户头像；短按打开资料卡。未绑定短按可进入引导。资料卡提供解绑，不提供“设为当前接待” |
| 2 | AI 金牌销售指导 | 未匹配画像时置灰并说明原因；绑定后可查看指导和待接待排行榜。支持新消息提醒 |
| 3 | 帮你回 | 默认生成后展示候选，用户复制；可配置生成后自动复制，但仍展示内容与复制反馈。支持编辑、重新生成与润色 |
| 4 | 常用素材 | 收藏、搜索、最近使用；宣传海报预览和分享，定型文预览和复制 |
| 5 | 更多 / 配置 | 模型、回复偏好、提醒参数、声音/震动、浮窗位置、权限引导、诊断、暂停/收起 |

工具条可拖动、左右停靠；展开面板一次聚焦一个任务。当前方案的正常工作位置是微信聊天现场；应用外展示和权限窗口行为属于真机集成验证项。

## 截屏识别与手动绑定

- 先用教程图示说明进入目标私聊、露出顶栏身份信息、收起键盘、停在目标消息位置。正文不要求固定格式。
- 点击识别后暂时隐藏助手浮窗，取得静态截图，恢复浮窗并显示识别状态。实际截图方式与权限流程在实现验证后确定；提供导入已有图片作为开发和失败后的入口。
- 检查页面类型和必要身份线索：列表、群聊、公众号仅辨别并排除，不继续提取正文、搜索业务画像或生成建议。缺少身份线索时说明具体缺项。
- 顶栏姓名/备注属于匹配线索，不能单独视为唯一客户 ID。画像搜索按工作账号和客户标识限定；多候选让用户选择，无匹配提供搜索/重试。匹配后立即显示客户姓名、头像和画像加载状态。
- 头像代表用户手动选中的客户；用户负责切换时重新识别或解绑，不增加自动会话跟随或“设为当前接待”。打开排行榜上的其他客户不会修改此绑定。
- 北京时间每天 18:30、22:00 自动解绑；不删除画像、指导历史或素材。错过定时点，下次启动按绑定建立时间补做：仅清除跨过解绑时间点的旧绑定，不清除时间点之后新建立的绑定。
- 解绑后该客户恢复参与提醒，已有待回复消息重新评估。

## 回复与销售指导

- 普通回复/润色可使用用户手动提供的上下文，画像是增强信息；未匹配画像不阻断这些功能。
- 发起生成前可见目标客户和上下文来源。点击生成才调用模型；自动复制由明确设置控制。
- 销售指导面板包含当前客户指导与待接待排行榜。排行榜展示客户、意向程度、最新消息摘要、同步时间，突出新消息；具体评分和排序算法待数据验证，不能凭空标为真实意向。
- 点击客户进入该客户独立 AI 指导会话，保留追问记录。支持“看最新消息给我建议”：更新该客户上下文并显示已读到的消息时间；尚未同步的内容可用截图或粘贴补充。
- 提醒文案用“我刚查到消息”，不把首次查到时间当作微信收到时间。数据时间和来源在详情可查。

## 提醒规则

- 高意向或可能流失客户的新入站消息触发提醒；排除头像当前绑定客户。高意向/流失信号先用明确标为模拟的数据验证，真实规则随方舟数据接入核对。
- 长时间未回复可重复提醒。设置分别配置首次等待时长、重复间隔、最多追加次数；具体默认值待交互测试，不视为用户已指定。
- 确认已回复结束该轮；支持稍后提醒和本次忽略。新消息与旧提醒之间的状态需按消息 ID 和会话方向去重归并，不能每次轮询重置追加次数或产生重复提示。
- 短暂闪动、持续红点、待处理数量，加震动与提示音。声音和震动可分别关闭，遵循系统静音/勿扰；同批提醒合并提示。数量按待处理客户计算，详情显示消息数量。
- 模拟验证未回复、已回复、同步滞后、连续入站消息、忽略/稍后、绑定排除、手动与定时解绑、应用重启恢复、批量提醒。
- 方舟尚未同步回复时可能误提醒。保留消息时间、首次查到时间、同步检查时间和提醒时间用于诊断，不编造真实入库时间。

## 实施顺序与交付

1. **交互原型和数据契约**：完成五入口可交互原型；定义图片识别、客户绑定、模型上下文、客户指导会话、素材、消息事件与提醒状态。明确模拟数据标签和真实数据替换接口。
2. **浮窗与静态识别闭环**：在无微信登录的模拟器运行工具条、资料卡、导入图片、画像搜索、绑定/解绑；建立不同布局、姓名/备注、重名、裁剪、键盘遮挡、通知遮挡和非私聊样本集，报告分类和匹配准确率及失败样本。样本来源与标注记录清楚。
3. **回复与指导**：接入已有测试模型通路，完成手动上下文、图片提取上下文、候选展示/复制、润色、客户独立指导与追问。密钥不进入 APK、仓库或诊断输出。
4. **素材与提醒**：完成海报/定型文、排行榜和可配置提醒；用可控消息序列和测试时钟验证定时点、重复次数、重启恢复及绑定排除。测试时钟不影响生产设备时间。
5. **真实数据接入**：验证方舟客户映射、消息方向与 ID、最新上下文、排序依据及同步时效；替换模拟适配器。无需等待模拟器微信登录成功。
6. **真机集成验收**：在用户操作的测试会话验证截图、头像绑定、浮窗与输入法、剪贴板/分享、音振/勿扰、前后台与定时行为，以及实际账号安全反馈。出现安全警告停止该轮并记录，不进行绕过或连续重试。

各阶段交付可运行产物、必要截图/演示、验证结果和未通过项。静态图片准确率、真实截图成功率、真实方舟时效与账号安全观察分别报告，不能互相代替。

## 尚需工程验证的选择

OCR/图片理解方案、截图授权与浮窗承载方式、图片处理位置和保留策略、提醒默认参数、真实画像头像可用性、方舟接入方式尚未验证。开发时给出实现依据，必要时再询问影响用户体验或数据使用的选择；不把工程假设记录为已实现能力。
