# QMYL 微信探针人工联合验证记录（2026-10-09）

本记录仅用于当前对话的联合验证，保留既有 `VERIFICATION.md` 与页面可读性对照，不代表整轮通过。时间均为电脑 PowerShell `DateTimeOffset` 的 Asia/Shanghai（UTC+08:00）时间；设备 Unix 时间仅在本机转换后对照，不把设备墙钟当作操作时刻。测试区间的起止需在每轮开始/结束观测时补记；单轮耗时优先用探针的单调时钟字段。

## 目标与边界

- 仅支持并验证微信客户一对一私聊：页面分类、顶栏与当前可见消息读取、输入法开合、同会话快照复用、切换会话后的旧结果失效、悬浮入口及扫描耗时。
- 群聊、公众号、列表等页面只辨别类型并排除；不读取正文、不匹配客户、不生成建议。
- 所有微信界面操作由郭子仪手工完成。本观察者只读采集、分析和记录；不通过 ADB 自动输入、点击、滑动、无障碍 action、键盘注入、应用启动或其他方式替用户操作微信，不生成、插入或发送消息。
- 历史资料记载专用模拟器曾出现账号异常退出及官方安全警告；当时同时有模拟器、无障碍读取、ADB 点击/滑动和 `uiautomator dump`，具体触发原因未知。只读和单独测试账号均不保证不触发风控。出现新的安全警告时立即停止当轮，不绕过、不伪装、不持续重试。
- 目标真机 OPPO A5x 5G / Android 15 / 微信 8.0.70 与模拟器结果分开记录，不用模拟器结果代替真机验收。

### 可实际观测与限制

- 通过探针报告/诊断可观测：页面分类、结构节点和可编辑节点数量、私聊快照节点数、顶栏候选的脱敏结构特征/固定分类信号、完整读取与快照事件、分类状态变化、悬浮入口决策/显示/失败、单调时钟 `scan_ms`、`structure_ms`、`body_ms`、扫描间隔与缓存节点数。
- `ProbeAccessibilityService` 在服务连接期间每约 300ms 安排一次扫描；读取开关是进程内变量。脱敏导出不包含该开关、账号或页面截图。报告的 `OTHER` 不足以证明读取开关当前开或关。
- 输入法开合可从系统 `dumpsys input_method` 状态、报告事件和屏幕画面交叉观察。画面/截图用于确认实际页面和遮挡；节点树读取不使用 `uiautomator dump`，因为既有资料确认它可能改变当前可访问窗口并导致无障碍服务重连。
- 当前可见消息正文只允许在用户明确指定的一对一测试会话中观察；日期记录仅留必要脱敏元数据/计数和判断，不留账号凭据、API 密钥或无关聊天正文。导出节点数不等于聊天气泡数，也不证明消息完整覆盖。
- 单次读到不等于持续稳定；页面分类、快照复用或失效各需按多次状态变化核对，样本足够前不宣称验收通过。
