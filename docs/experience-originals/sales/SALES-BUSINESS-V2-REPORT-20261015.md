# 销售助手业务规则接入报告

日期：2026-10-15（开发机日期，Asia/Shanghai）。本轮仅本机服务源码实现及验证，未部署线上，未更换工作机 APK。

## 已实现

- 核对 3chat 总提示词及六份任务。运行提示词独立于平台工具，不安装/执行 3chat 宏，不写飞书/方舟，不自动转人工或发消息。
- 新增 sales_prompts.py：三套可审阅提示词，版本 sales-business-v2；领域角色为高考美术培训顾问。帮我回使用模型内场景选择，不另起一个分类模型请求。
- 场景优先：风险承接、售后、报名、选课、答疑、一般回复。明确已报名客户当前售前新需求仍以当前诉求判断，不凭阶段强推课程。
- 画像存储新增 facts/inferences/unknowns。8 项事实覆盖身份、阶段、方向、目标、基础、偏好、具体报名状态、已选班型；推断限定意向/情绪，附理由和消息 ID。服务校验引用 ID 在本次输入中存在，不代表服务已证明语义一致。
- 保留旧 summary 接口；模型若只给摘要，结构字段留未知并标 structured_fields_available=false，不伪装已提取字段。摘要仍是模型文字，未实现逐句事实校验。
- 保留预报名、付款办理、在读等具体表述，不将预报名改为已付款；当前意向允许因明确新证据降低，不沿用只升不降。
- 润色脱离方舟身份读取、聊天拉取和画像生成，仅使用原文与可选缓存画像。仍需既有工作机授权和已确认客户，未改变访问控制。
- 帮我回标出最近客户消息及后续对话，明确它不必然是待回复消息；销售补充不冒充客户原话。无消息 ID 的精确人工选择入口尚未新增。
- 任务结果补充 scene、warnings、prompt_version、reply_target_message_id。拦截 NULL、单独转人工和工具占位符。

## 缓存及兼容

画像仍按工作号 ID+客户 ID 隔离，SQLite 保存于服务数据目录；沿用原有队列、24 小时 stale 标识和任务保留规则。新提示词版本使旧版本画像不命中无变化缓存；首次新版本读取回到限定近 30 天窗口，之后沿用成功画像检查点及一天重叠。每次最多 6 页、300 条返回，模型输入还有字符预算，不宣称完整历史。

旧画像只作为历史未复核背景，新结构事实必须引用当次消息。结构 facts 不等于所有历史事实的永久累加；未出现在新窗口的信息可能转为未知，历史摘要仍供参考。未新增批量生成、夜间任务、生命周期清理或自动写回。

## 实际验证

- 后端 56 项回归测试通过：原有销售服务、消息读取、模型配置与生成测试，加 9 个新增案例（含参数化）。覆盖无上游可用时润色、客户回复对象、结构画像保存、伪造证据拒绝、平台控制词拒绝等。
- DeepSeek 使用已有销售密钥，仅测试合成对话，不读取真实客户聊天。本轮三次评估，每次 8 项：退款、售后、试听、选课、价格、致谢、润色、画像。调用耗时来自开发机 monotonic；单次观测不构成 SLA。
- 第一次：6/6 场景标签正确，但多场景一次索取多字段，致谢夹带招生入口，语义未通过。
- 第一次修订后：退款仍索取姓名及电话；画像将询价延伸为情绪风险，未通过。
- 第二次修订后：最终 6/6 场景标签正确；人工检查 6 个回复无多字段收集，致谢为“不客气。”；润色保持原意；画像证据 ID 合法，普通询价不生成情绪风险。此后停止调参，不声称随机模型能稳定保证所有场景。
- 首次 pytest 因系统临时目录权限失败；改项目内专用 basetemp 后测试通过，无修改系统目录权限。

证据目录：docs/evidence/sales-business-v2-20261015/；最终 model-results.json，前两轮 model-results-round1.json、model-results-round2.json，回归 pytest.xml。全部模型示例为合成数据。

## 提示词输入与输出

画像输入：双标识 target、previous_profile、带 msg_id/sent_at/direction 的 messages、coverage。输出 profile_summary、facts、inferences、unknowns；在画像中保存版本、模型、生成时间与范围。

帮我回输入：identity、profile、recent_messages、reply_target、latest_situation、business_materials=[]。当前无独立有效业务知识库，所以未知价格、优惠、名额、政策只能核实，不凭历史聊天确认为现行事实。输出 draft、scene。

润色输入：original_text、latest_situation、可选缓存 profile；recent_messages 为空、chat_fetched=false。输出 draft、scene=polish、warnings。危险原文承诺可改为需核实表达，但应返回调整说明；Android 尚未新增 warnings 的展示，需销售审阅草稿。

全文见 SALES-BUSINESS-PROMPTS-V2-20261015.md；运行源以 sales_prompts.py 为准。
