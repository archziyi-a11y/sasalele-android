# 首批销售发布前的管理员发机与Android15验收

目标：管理员逐台发机，销售手机直接联网访问正式服务；无人员登录、无开发电脑连接。资源未填、服务未部署时不安排销售反复试连接。

## 观测就绪后再请用户操作

必须先落实真实域名/HTTPS/运行服务器、上游只读凭据和正式签名包；管理员完成独立工作机配置及在线健康检查。原因：否则真机失败无法区分手机网络、服务不存在或权限未配，安装包存在不能替代上线。

记录条件：确定测试工作机资产编号、Android版本、网络类型、授权的工作号与私聊双标识；记录PC/server的ISO+08:00时间、手机时钟来源与偏差，不修改设备时钟。保存请求编号、HTTP结果、耗时、消息数量及覆盖元数据，不保存无关聊天正文/凭据。手机截屏证据只保存必需且私有，不能进Git。

## 用户先真机验证（不是模拟器验收）

1. 管理员安装固定签名正式包、导入该工作机配置文件，服务检查通过；删除手机传输配置文件及传输副本。销售无需知道IP或访问码。预期授权范围正确。
2. 用户在WiFi及5G分别检查服务，再在合成聊天页短按资料/长按截图，系统授权允许和取消。预期短按不开截屏；允许捕获原画面、没有助手覆盖或主页；取消/超时恢复助手。
3. 先用合成名称验证导航数字不被选为姓名；对已授权实际私聊截图，只提取顶栏名称。有群聊/公众号/列表线索时排除，不能继续取正文。无法判断显示不确定。
4. 自动跨号搜索，检查同名多个候选不合并，筛选/无匹配/翻页；人工确认指定双标识，基础事实、历史摘要缺失/陈旧与写入时间分层。确认后只取该客户近期私聊窗口。
5. 请求帮我回上下文，补充局面和类型，核对目标、方向、发生时间、消息ID、窗口和截断标记。当前不接实际模型，不自动复制/发送。
6. 连续截两名不同客户、快速修改姓名/请求；旧响应不得覆盖新目标。断网后反馈手机网络，恢复联网再重试；只读瞬时传输中断最多重试一次，确认绑定不自动重试。
7. 管理员重启业务服务，设备凭证与确认缓存保留，聊天仍按需刷新；暂停服务/模拟上游失败，反馈与查询编号可定位。撤销测试工作机后立即拒绝，其他授权工作机不受影响；重新发机配置后恢复。
8. 点击浮窗外逐级返回，收起点击不落到底层；选图备用实际授权、预览/OCR、处理结束或取消后临时图片清理；捕获服务释放资源。
9. 覆盖升级验证保留工作机配置、截图和材料正常；卸载重装必须由管理员重新发机，不要求销售重新登录。

每项记录：设备/网络/步骤、预期、实际、通过或失败、请求编号、起止时间、证据路径。无法验证标待验，不写“全部通过”。Android15后台与浮窗/省电策略必须实机验证；API36模拟器不替代。

## 发布门槛

正式资源落实、HTTPS证书链有效、授权检查/撤销/重启验证、真机WiFi和5G闭环、固定签名及版本升级、已知凭据/真实样本APK扫描全部有证据后才能给第一批销售发布。失败项先定位修正后少量复测；相同原因两次修复仍失败记录阻碍，不无限重复用户操作。
