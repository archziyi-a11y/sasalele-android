- 新增 `marketing-chat-insight/src/mktci/sales_generation.py`：沿用既有画像摘要提示词和阶段/标签规则，单客户按需生成；不调用旧按日作业，不写飞书/方舟。
- 画像和任务使用独立 `sales-generation.sqlite`，非破坏性建表。画像以工作号ID＋客户ID隔离，含生成时间、覆盖信息、模型/提示词版本及消息指纹，服务重启保留。
- 初始读取近30天、最多6页×50条；后续在未触及分页上限时从上次消息时间前1天重叠读取，按消息指纹识别变化。最多保留1000个消息指纹；不建立原始聊天长期归档。
- 同客户相同生成请求合并，有界队列20、模型并发1；等待模型不持有业务全局锁。模型请求连接超时10秒、网络读写预算90秒；无自动付费重放。
- 输入优先保留最新消息，未知方向明确保留，附件不假装为文本转写；旧画像与新消息滚动生成。无新文本可保留已有画像，不推进覆盖时间；无任何可用画像和文本则明确失败。
- 阶段/标签仍为既有关键词规则，不宣称已验证美术高考业务准确率。旧画像阶段在新消息未形成新阶段时保留；标签仍反映本次输入，不代表完整生命周期标签。
- 新增 `/sales/profile/ensure`、`/sales/jobs/{job_id}`、`/sales/draft`；沿用设备授权与人工确认检查。草稿区分帮我回和润色，润色必须提供原文；模型异常仅映射安全错误码。
- 飞书客户端不再默认初始化。生产默认独立画像；测试显式注入旧飞书客户端时仍可回归历史路径，不修改飞书原作业。

## 接口概要

所有接口沿用现有Bearer工作机授权；不新增销售登录。

- `POST /sales/profile/ensure`：`account_id, friend_id`，须人工确认过，返回任务ID、状态及已有画像。
- `GET /sales/jobs/{id}?account_id=...&friend_id=...`：核对任务客户；返回queued/running/succeeded/failed/interrupted和安全错误码。过期任务明确返回410。
- `POST /sales/draft`：双标识、request_type、latest_situation、original_text、request_id。同输入及相同幂等ID复用已成功任务，活跃同客户画像任务合并。
- 画像结果包含summary、stage、tags、source、summary_generated_at、revision、coverage。手机不接收内部消息指纹。

脱敏草稿结构：`{"draft":"合成草稿","request_type":"帮我回","profile_revision":"合成版本","coverage":{"complete_history":false},"generated_at":"带时区时间","model_called":true}`。
