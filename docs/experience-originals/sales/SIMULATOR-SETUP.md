# 0.1.7 模拟器联调

目标是先在 Android 模拟器验证微信私聊识别、输入法与悬浮入口，并用手动粘贴的上下文测试 DeepSeek 草稿。模拟器结果不代表 OPPO A5x 5G / Android 15 的最终行为。

1. 运行探针专用 AVD `QMYL_Probe_API_36`（Android 16，端口 `emulator-5556`）。Android Studio 的 `Zibai_Pixel_API_36` 是另一台模拟器，不用于本项目测试。探针专用 AVD 安装微信官网版 8.0.79 后，登录由账号持有人在该模拟器内完成。个人微信测试不要选择 [工作号尾号已脱敏] 工作号，而应在应用首页手动选择“个人微信 · 模拟器测试”。这个模式不匹配方舟客户画像。
2. 在电脑上执行 `python tools/deepseek_relay.py` 启动本地服务。服务只绑定 `127.0.0.1:18973`，从当前 Windows 用户目录 `AppData/Local/QMYL/deepseek-key.txt` 读取 DeepSeek 密钥；不要把密钥写入 APK、仓库或测试记录。可用浏览器访问 `http://127.0.0.1:18973/health` 检查服务是否启动。
3. 执行 `adb -s emulator-5556 reverse tcp:18973 tcp:18973`，使模拟器内的 `127.0.0.1:18973` 指向电脑本地服务。模拟器重启后需重新执行。在应用首页点“检查电脑端模型桥接”，应提示已连接。调试 APK 使用明文流量仅访问经 adb reverse 转发的本地地址；正式版未加入网络权限。
4. 在系统设置启用探针无障碍服务、启用并选择探针输入法。应用首页开启本次读取，可按需开启私聊悬浮入口。进入已登录微信的一对一私聊；群聊、公众号和其他页面不作为业务场景。
5. 在当前私聊的输入法“回复”页，先选“选择对象 → 绑定当前对话”。这只是个人号的本次测试绑定，不证明联系人身份。手动复制需要给模型的上下文，再点“粘贴上下文”和“帮我回 · 生成草稿”。只有这段粘贴内容会上传至 DeepSeek；生成完成后先核对，点“插入输入框”，可在微信编辑框继续修改，最后由人决定是否发送。
6. 切换会话、对象或编辑框，以及取消请求时，旧结果应丢弃；离开私聊或识别不稳时悬浮入口应收起、候选插入应禁用。高意向推荐等待方舟数据接入，当前没有业务排序结论。

当前尚未完成微信登录后的分类、悬浮入口和模型到输入框全链路验证。现阶段已核验本地桥接健康检查和用虚构文本调用 DeepSeek 成功。测试时不要把私人聊天正文写进命令行或导出日志。
