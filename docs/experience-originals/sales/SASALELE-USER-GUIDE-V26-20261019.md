# SASALELE 销售助手使用引导

适用版本：首个正式版 v26（1.7-ui-preview）。更新：2026 年 10 月 19 日。

SASALELE 帮你了解客户、梳理下一步、润色文字、查看待跟进联系人和使用销售素材。你照常在工作机微信里与客户沟通，助手从屏幕侧边打开。

**先记住三件事：选对工作号、看清当前客户、审阅后自己发送。**

## 一、第一次使用：开启助手，选对工作号

管理员应先完成安装和业务服务配置。日常使用无需连接电脑或另行注册登录。

1. 打开 **SASALELE 销售助手**。
2. 如显示 **开启悬浮窗权限**，点击后在手机系统设置里允许 SASALELE 显示悬浮窗，再回到应用。
3. 点击 **开启助手**，屏幕侧边出现工具条。
4. 点击工具条 **齿轮 → 当前工作号 → 选择工作号**（已选过时显示切换入口），选中本机微信使用的工作号，再点击 **使用此工作号** 确认。
5. 回到微信开始使用。

**必须：选择与本机微信实际使用一致的工作号。** 客户查找、画像、销售指导和提醒都使用这个选择；选错可能找不到客户或查看错误账号下的资料。不知道该选哪一个时请培训人员或管理员核对，不猜选。

工作号选择会保存，无需每次重新选。换用其他微信工作号时，再到设置切换。

如果没有工具条，先回 SASALELE 检查悬浮窗权限并点击开启助手。若提示未配置或授权失效，交给管理员处理。

## 二、认识侧边工具条

从上到下是收起箭头和六个功能：

| 图标 | 功能 | 什么时候用 |
|---|---|---|
| 箭头 | 收起／展开 | 工具条挡住操作时收起；拖动箭头或收起后的圆钮可调整位置 |
| 人像／客户头像 | 客户资料 | **短按**看当前客户资料；**长按**截屏识别 |
| 星星 | 销售指导 | 想判断当前局面、下一步如何沟通 |
| 对话气泡 | 帮我回／润色 | 起草回复，或改善自己写好的表达 |
| 铃铛 | 智能跟进提醒 | 看近 15 天活跃联系人中的待查看对象 |
| 图片叠层 | 销售物料 | 找图片、文字或链接素材，复制或分享 |
| 齿轮 | 助手设置 | 选择／切换工作号，调整提醒等设置 |

打开功能后工具条会暂时隐藏。点击面板右上角 **关闭面板**，回到工具条。内容显示不全时，在面板里上下滑动。

## 三、识别当前客户：长按 → 截屏 → 核对 → 确认

### 1. 准备聊天画面

在工作机微信打开要处理的**客户一对一聊天**，让顶栏的客户姓名／备注露出来。建议先收起键盘、等待通知横幅消失。

**必须：截图画面要有完整客户聊天顶栏。** 助手据此识别姓名；遮住或截掉顶栏会找不到名称或识别错对象。群聊、公众号、聊天列表不用于这项识别。

### 2. 获取截图

1. **长按人像／客户头像**。
2. 手机出现系统录制／投放授权框时，按提示选择整个屏幕并点击 **开始**。这是本次截图的系统授权步骤。
3. 等待助手恢复并显示识别结果，不要立刻切到另一个聊天。

如果截图没有成功，可进入客户查找页，点击 **选择已有图片**，使用手机系统截屏保存的目标聊天图片。

### 3. 修正名称，确认匹配

1. 看姓名／备注输入框是否与微信顶栏一致。
2. 有错字可直接修改，等待查询；也可点击 **刷新／重试**。
3. 在候选中核对**姓名／备注、头像和工作号**，点击 **查看并人工确认**。
4. 确认是同一客户后，点击 **人工确认绑定**，进入客户资料。

**必须：确认目标客户后再生成建议。** 同名不代表同一人；无法判断时先返回核对，不靠猜测绑定。候选页可能显示编号供管理员排查，日常主要依据姓名、头像和工作号核对。

### 4. 换客户时重新识别

**必须：微信切换到另一位客户后，重新长按头像识别，或在资料页点“切换客户”。** 助手不会自动跟随微信更换对象；没有重新确认时，仍可能显示上一位客户的资料和建议。

每次生成前看一眼页面上的客户名称。

## 四、客户画像：先看概况，再看跟进判断

短按客户头像打开资料。主要内容包括：

- **客户概况**：当前背景、需求和进展的摘要。
- **关键背景**：已有资料中能明确整理出的信息。
- **跟进判断**：结合记录形成的工作判断及依据。

首次进入时可能自动读取或生成，显示进度时请等待。若没有可用画像，点击 **生成画像**；已有画像需要更新时，点击 **更新画像**。

**画像不是当前微信完整聊天的实时镜像。** 记录较少时可能提示“聊天记录较少，画像供参考”；最新一条微信消息也可能尚未被服务读取。结合你刚看到的对话使用，有变化时更新；生成指导时也可补充最新局面。

“画像来源与时间”“更多”用于需要核对时查看。资料缺失、更新失败，不等于客户不存在；不要连续反复点击生成。

头像暂时没有已选客户时，按识别流程重新确认即可；不需要因此重装应用。

## 五、销售指导：回答“这位客户下一步怎样跟”

1. 确认客户后，点击 **星星**。
2. 看清 **当前客户**。
3. 在 **补充局面或本次希望解决的问题（可选）** 中，写你希望解决的具体问题。
4. 点击 **生成销售指导**，等待结果。
5. 阅读 **本次跟进建议**，决定下一步。需要保存到别处时可点 **复制指导**。

补充问题可以这样写：

> 家长想了解寒假安排，孩子高二，时间还没确定。这一轮我应该先确认什么？

> 客户说先考虑，之前已经介绍过班型。请帮我找一个自然的跟进角度。

**销售指导给你内部参考，不应整段当作对客话术发送。** 涉及具体课程安排、费用或政策，使用已确认的业务资料。

修改补充问题后，已有结果会标记为上次输入的结果；重新生成成功后才替换。需要留存的文字请及时复制到你的工作记录，不把面板当作长期笔记本。

## 六、帮我回与润色：生成后仍需自己审阅

### 润色：已有原文，想把话说得更清楚

1. 点击 **对话气泡 → 润色**。
2. 看清当前客户，将自己写好的话放入 **待润色原文（必须填写）**。
3. 必要时补充局面，再点击 **生成润色**。
4. 查看结果及必要的调整说明；可以直接编辑结果。
5. 点击 **复制草稿**，回到正确的微信聊天，粘贴、检查后自己发送。

例：

> 原文：我先帮您问一下老师时间，确定了再跟您说，您先不用着急。

润色无需先有画像，但仍应在助手中确认当前客户。画像可辅助语气，不能替代你写原文。

### 帮我回：需要一条回复草稿

1. 点击 **对话气泡 → 帮我回**。
2. 看清当前客户，在补充局面中写清本次要回复的问题，尤其是刚收到的新消息。
3. 点击 **生成帮我回**，审阅并按实际情况编辑。
4. 点击 **复制草稿**，自行粘贴发送。

**本次培训以润色为主要练习；帮我回先演示草稿流程。** 当前课程知识库仍待完善，不依靠它直接确认报价、优惠、名额、排课、住宿和退款结果。这类信息按你手头的有效业务资料确认后再发送。

**必须：发送前核对聊天对象、原意和具体事实。** 助手只生成/复制，不自动发送；复制成功也不等于微信已经发出。日常按“审阅 → 手动复制 → 粘贴 → 自己发送”操作，不依赖设置中的自动复制开关。

## 七、智能跟进提醒：看谁需要查看，不是催你给所有人发消息

点击 **铃铛**进入。页面显示当前工作号、近 15 天活跃人数和待查看人数。

| 操作 | 作用 |
|---|---|
| 刷新列表 | 更新联系人列表；同步中先等待，不连点 |
| 全部活跃 | 查看该范围内的其他活跃联系人；可再切回只看待查看 |
| 点击联系人卡片 | 复制该联系人的昵称／备注；回微信搜索后进入聊天，不会自动跳转 |
| 已处理 | 当前这条提醒已看过并处理；不是代你回复微信 |
| 稍后 | 暂缓处理，当前设置为约 1 小时后再评估 |
| 更多 → 忽略此联系人 | 适合不参与客户跟进的同事等对象，后续新消息也不再提醒 |
| 忽略列表 → 移回提醒列表 | 恢复误忽略对象；是否显示为待查看取决于最近消息状态 |
| 同步详情 | 查看上次同步时间，显示为北京时间 |

“客户最后发来消息 · 待查看”表示助手读到的最近对话方向，不等于系统认定你必须回复。可能是致谢、已经结束的话题，也可能存在同步延迟。先看微信真实聊天再决定动作。

第一次导入的历史联系人主要用于建立列表，不要等每位联系人都弹出通知。正常使用保持助手运行和联网；离线或关闭助手时不要期待列表持续实时更新。

**列表看得到客户，不等于头像已经切换到该客户。** 从列表回微信处理另一人时，若要生成画像或建议，仍按识别流程确认对象。

## 八、销售物料：找、加、复制、分享

点击 **图片叠层图标**进入物料页。

### 查找素材

- 搜索框按**物料标题**查找。
- 右侧 **漏斗** 可选全部／图片／链接／纯文本，并可叠加搜索。
- 查不到时看看是否还开着类型筛选，可点 **清除筛选和搜索**。

### 新增文本或链接

1. 点击右上角、图片按钮左侧的 **文本图标**。
2. 填写 **物料标题** 和 **文本内容或完整链接**，点击 **保存物料**。
3. 标题、内容都要填写；只粘贴完整 `https://…` 或 `http://…` 网址会归为链接，其余为纯文本。

“一段说明加一个网址”仍归纯文本；取消新增不会保存。保存后原有筛选会清除，便于看到新内容。

### 新增图片

点击右上角 **图片图标**，在手机选择需要的图片，按系统提示完成导入。

### 使用素材

- **文字／链接**：点击复制，回微信粘贴并检查。
- **图片**：点击 **复制图片**，回微信使用可用的图片粘贴入口；若本机没有该入口，使用 **分享图片**，在系统分享面板选择微信及正确对象。
- **删除**：点击素材下方删除，再确认；误点时取消。

素材保存在**当前手机**，不要把某台新增素材理解为所有工作机自动同步。可用且仍有效的资料再保存和分享；实际发送前仍核对对象。

## 九、遇到问题，按现象处理

| 现象 | 先做什么 | 仍不行时 |
|---|---|---|
| 找不到工具条 | 回应用核对悬浮窗权限，点击开启助手；检查是否收起为箭头 | 请管理员检查系统限制 |
| 微信截图失败／空白 | 保留目标聊天，用手机系统截屏后选择已有图片 | 告诉管理员“微信失败、其他页面是否能截”；由管理员检查手机共享保护，不在现场盲改一串设置 |
| 姓名识别成数字或错字 | 确认顶栏露出，手工改正确姓名／备注 | 核对工作号，再交管理员处理，不猜选同名客户 |
| 显示上一位客户 | 重新识别并确认当前客户 | 在新客户确认前不生成建议 |
| 没有画像／聊天不足 | 核对客户，确认本次有可用记录；可先用自己的原文润色 | 反馈该工作号、客户备注和提示，不反复生成 |
| 生成失败／等待超时 | 保留已有结果，记录提示，确认联网后再试一次 | 停止连点，反馈给管理员；超时不一定代表后台任务已取消 |
| 尚未取得提醒列表 | 核对工作号，点击一次刷新并等待同步状态 | 反馈提示和时间；不要当成“没有客户” |
| 复制后微信没有内容 | 确认点的是复制按钮；文本长按输入框粘贴，图片可改分享图片 | 反馈手机和具体素材类型 |
| 键盘挡住结果 | 收起键盘，再滑动面板；必要时退出面板重新打开 | 记录截图请培训人员协助 |
| 授权失效／业务服务未配置 | 联系管理员 | 不卸载、不清数据、不自行重新配置服务 |

反馈只需说明：**手机、当前工作号、正在做哪一步、出现什么提示、发生时间（北京时间）**。附问题画面时只保留必要部分，不在培训群发送完整客户聊天。

## 十、培训后的五项自查

- [ ] 我能开启助手，确认当前工作号。
- [ ] 我能长按截图、修正名称、确认客户；换客户时会重新识别。
- [ ] 我能区分画像、内部销售指导和对客草稿。
- [ ] 我能编辑并复制一条润色结果，知道仍需自己粘贴发送。
- [ ] 我能使用跟进列表和物料，知道如何恢复误忽略联系人。

培训示例优先用测试会话和虚构文字。操作真实客户前确认对象；无需为了练习向真实客户发送测试内容。

---

文档说明：按 v26 当前主入口及源码核对，未包含后续知识库、自动营销、自动发送或跨手机素材同步承诺。具体手机系统授权样式可能不同，以当场提示为准。
