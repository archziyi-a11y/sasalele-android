# Historical design media

The 183 files in `DESIGN-MEDIA-SHA256.csv` preserve reviewed application design,
synthetic-service UI tests, and development recordings. Original file bytes are
preserved; the inventory records SHA-256. They do not establish current production
behavior or constitute a new functional acceptance run.

`evidence/native-ui-v32/verified-followups.mp4` contains only one video sample and
has no reliable container duration. It is retained as an incomplete historical
recording, not a complete interaction demonstration. The reviewed recordings have
no audio tracks; their `mett` data tracks contain Android screen-recording timing
metadata.
